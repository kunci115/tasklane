# Third-party material

The console bundles three typefaces, served from the binary (no external font requests). All are licensed under the SIL Open Font License 1.1; the license texts are in `crates/tasklane-server/assets/fonts/`.

| Font | Use | License file |
|---|---|---|
| Inter | body text | `OFL-Inter.txt` |
| JetBrains Mono | code, labels | `OFL-JetBrainsMono.txt` |
| Chakra Petch | headings | `OFL-ChakraPetch.txt` |
